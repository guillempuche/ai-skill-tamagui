# ai-skill-tamagui

Tamagui styling, themes, tokens, compiler, and UI kit for React and React Native. Use when the project uses or is adopting Tamagui and you are writing or debugging its components, config, or compiler setup.

## Install

```bash
# Add marketplace (uses repo slug)
/plugin marketplace add guillempuche/ai-skill-tamagui

# Install plugin (plugin name is topic-only)
/plugin install tamagui@guillempuche-ai-skill-tamagui
```

## Part of AI Standards

This skill is also available in the [ai-standards](https://github.com/guillempuche/ai-standards) bundle with other skills and agents.
